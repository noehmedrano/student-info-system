# Student Information System

## Project Description
The Student Information System is a Python application that manages student information. It supports adding, viewing, searching, updating, and deleting student records.

## Objectives
- Develop a simple student information management system.
- Apply modular programming.
- Store student records in JSON format.
- Implement logging and error handling.
- Use Git and GitHub for version control.

## Features
- Add new student records
- View all student records
- Search by student ID
- Update student information
- Delete student records
- Save data in JSON
- Store configuration in a separate file
- Record application activities in a log file

## Technologies Used
- Python
- JSON
- Visual Studio Code
- Git
- GitHub

## Project Structure
- `src/models/` - Student model
- `src/services/` - Student data operations
- `src/utils/` - Logging utility
- `src/main.py` - Main menu
- `data/` - Student records
- `config/` - Application settings
- `logs/` - Application logs
- `tests/` - Automated tests

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `python -m src.main`.

## Data Storage
Student records are stored locally in `data/students.json`.

## Limitations
- The application uses a command-line interface.
- Data is stored locally, not in a cloud database.
- User login and multi-user access are not implemented.

## Future Improvements
- Add a graphical or web interface.
- Integrate a cloud database.
